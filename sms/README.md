# SMS

Not built yet. Sending SMS in India needs a DLT-registered sender (entity ID, header and approved templates)
and an SMS gateway account (for example MSG91, Kaleyra or Twilio). When one is chosen, the SMS tool will live
in this folder with the same pattern as WhatsApp: a phone column in each brand tab, a per-brand template,
limits in the Limits tab and a log.
